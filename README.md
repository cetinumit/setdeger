# SetDeğer

Aynı ekranda iki takımın oynadığı futbol scouting oyunu. Geçmiş sezonlardan isimsiz kartları o zamanki fiyatından alırsın; kartlar açılınca oyuncunun bugünkü değeri çıkar ve kâr edilir.

```bash
npm install
npm run dev      # http://localhost:5173
npm test
npm run build    # dist/ -> herhangi bir statik hosting
```

Ayrıntılar: `MASTER_PROMPT.md` (şartname), `CLAUDE.md` (durum), `docs/analiz.md` (kaynak analizi).
Veri: transfermarkt-datasets (CC0), güncel değerler 12.06.2026.
